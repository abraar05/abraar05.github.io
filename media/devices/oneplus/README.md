@# Media overrides for oneplus

Drop real device photos here as <model-slug>.webp (WebP, ~200 KB max).
The slug is the model name lowercased, non-alphanumerics replaced with dashes.

Example: iPhone 16 Pro Max 256 -> iphone-16-pro-max-256.webp`n
Photos should be:
- Straight-on, centred, clean background
- ~400x800 px (2:1-ish), WebP lossless or q85
- No watermarks, no UI overlays

The vector renderer is the fallback when no media file exists.
